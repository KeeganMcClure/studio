# Play

House rules for how every game treats the player. Each game's `bible.md` adds its own on top.

## No accidental point of no return

Set Nov 23, 2026, from Black Lantern's demo playtest, where you could walk into the Gleaner fight by accident. Black Lantern's "The boss waits for you" (Systems, Gameplay loop) was the first case of it.

- Anything you can't undo starts only when you choose it: a boss fight, leaving a place you can't come back to, ending a chapter or case, and spending or losing something you can't get back.
- The last step in shows a plain choice, such as **Go in / Not yet**, that says what happens. The cursor starts on Not yet, so mashing A can't start it.
- Everything optional in that area can be reached without crossing the spot that starts it.
- Ordinary fights you walk into (roamers, road events, ambushes) don't need the choice. Each game's bible says which of its fights are ordinary.

## Picks from a pool don't repeat

Set Nov 23, 2026, after the same home scene played twice in one Black Lantern home phase.

- When a game picks a scene, line, event or name from a pool, it doesn't pick the same one again until every other one in the pool has shown. That counts for everyone in the party, not just one character.
- The spec says how long the memory lasts (one phase, one case, one run) and whether it goes in the save. A game whose seed must replay the same way keeps the list in the save.
- If a pool is smaller than one stretch needs, the spec says so and the Designer grows the pool, rather than letting it repeat.
