# Rushlight Build Bible

Nov 19, 2026 · @Keegan

This doc is the single source of truth for Rushlight. When it disagrees with the project instructions or an old chat, this doc wins. Claude reads the tab a task needs before building, and logs every finished task in the Changelog under Process.

The [Black Lantern Build Bible](https://claude.ai/code/artifact/683b7cba-4aa4-4f3b-98c0-b45dded13138) is reference only and is never edited from this project. Claude reads only the tab a task needs (Systems, Agents and items, Skills and menus, Combat, Tech, Process, Art), never its story, agency-arc or spoiler material. Every ported rule is tracked in the Ported rules tab: carried over as is, changed (and how), dropped, or still undecided, with the reason.

Your original pitch is in [Medieval spin-off notes](https://claude.ai/code/artifact/ff65725f-726c-4558-80c7-4e0a90b647b8), and word for word in the Ideas inbox under To do.

## Comments

I will leave comments in (( )). When I prompt you to go through comments, review each one and return "Comment #X: \*\*your response\*\*" for me to review. "Apply changes" means edit the Bible itself: every change goes in directly, rewordings included (set Nov 20). The Changelog says what changed, and the doc's history keeps the old text.

Reading level (set Nov 21): everything Claude writes for this project, in chat, in the Bible and in the game, sits at an average reading level. Plain words over jargon, game or period.

## Art assets

Standing rule (set Nov 20): before making any art from scratch, Claude checks for premade assets first, on the Shared Shelf and in Rushlight's Asset Library and then in free online sources (with licenses that allow personal use). Claude only draws something new when nothing fitting exists, and says what it checked.

## Tabs
