# Rushlight

Phone-first dark fantasy roguelike, played in a Game Boy Advance-style shell. Forked from Black Lantern's code on Nov 21, 2026 (a clean copy of the kept parts, no history). Design lives in the Rushlight Build Bible; this repo holds the game code.

- `npm run check`: bundle the game into `dist/index.html` and run the automatic playtest checks
- `npm run build`: bundle only

Build rules for Claude are in `CLAUDE.md`.
